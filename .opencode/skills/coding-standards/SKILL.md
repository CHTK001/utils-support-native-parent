# Java 编码规范

该技能定义了所有 Java 代码必须遵守的编码规范，适用于整个项目。

## 规则

1. **中文详细注释** — 所有类、方法、字段均需中文注释
2. **属性必须多行注释** — 字段属性必须使用 `/** ... */` Javadoc 多行注释，不允许单行 `//` 行尾注释
3. **注释必须在代码上面** — 单行注释 `//` 和多行注释 `/** ... */` 必须放在代码上方，不允许在代码行尾
4. **类注释添加 @author CH** — 每个类必须有 `@author CH`
5. **if/else/while 大括号** — 即使只有一行也必须加 `{}`
6. **代码不允许压缩成一行** — 每个语句独立一行，不允许 `if (x) return y;` 等压缩写法
7. **lombok/record 简化代码和日志** — 使用 `@Slf4j`、`@Getter`、`@Setter`、`@Data` 等简化样板代码，数据载体使用 `record`
8. **删除 package 上方的注释** — `package` 声明之前不能有任何注释
9. **lombok 和 record 简化代码** — 同上第 7 条
10. **record 注释在类上** — `record` 的注释写在类上而非字段上
11. **修复代码上的问题** — 检查并修复所有编译警告、潜在的 NPE、资源泄漏等问题
