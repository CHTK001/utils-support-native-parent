## 2. 数据流：用户新增一个爬虫 → 自动定时执行 → 数据入库

```mermaid
sequenceDiagram
  autonumber
  participant U as 用户
  participant UI as 前端 (vue pages/spider)
  participant Ctl as SpiderDefinitionController
  participant Svc as SpiderDefinitionService
  participant Cache as Caffeine
  participant DB as MySQL
  participant Sch as SpiderScheduler (1s tick)
  participant Exe as SpiderExecutionService
  participant FE as FlowEngine
  participant Snap as SnapshotStore
  participant SSE as SpiderSseController
  participant Log as 浏览器 EventSource

  U->>UI: 填表单（code/URL/cron/flow）
  UI->>Ctl: POST /spider/definitions
  Ctl->>Svc: save(def)
  Svc->>Cache: @CacheEvict(allEntries=true)
  Svc->>DB: INSERT spider_definition + flow JSON
  DB-->>Svc: id

  loop 每秒
    Sch->>Svc: listEnabled() [@Cacheable 命中]
    Svc-->>Sch: List<def>
    loop 每条 def
      Sch->>Sch: CronExpression.nextExecutionTime(lastRunOr0)
      alt 到点
        Sch->>Exe: execute(def)
        Exe->>FE: parseJson(flowJson).createGraph().createInstance().run()
        loop 每个节点
          FE->>Snap: persist(before/after)
          Snap->>DB: INSERT spider_execution_log
          Exe->>SSE: send(event)
          SSE-->>Log: data: {nodeKey, status}
          Log->>UI: 更新节点状态（呼吸/徽章）
        end
        FE-->>Exe: context
        Exe->>DB: INSERT spider_data_record
        Exe->>DB: UPDATE spider_definition.last_run_*
      end
    end
  end
```

## 6. traceId 全链路追踪

```mermaid
sequenceDiagram
  autonumber
  participant U as 用户
  participant F as SpiderTraceFilter
  participant Ctl as Controller
  participant Exe as ExecutionService
  participant Flow as FlowEngine
  participant Log as spider_execution_log
  participant UI as 前端详情页

  U->>F: GET /spider-api/spider/...
  F->>F: 生成 traceId = UUID<br/>MDC.put("traceId", traceId)
  F->>Ctl: filterChain.doFilter
  Ctl->>Exe: execute(def)
  Exe->>Flow: parseJson(json)<br/>executionNo 透传 traceId
  loop 节点 N
    Flow->>Log: INSERT ... traceId, executionNo, nodeKey
    Flow->>Flow: MDC.put("traceId", traceId)
  end
  Flow-->>Exe: context
  Exe-->>Ctl: result
  Ctl-->>F: response
  F->>F: response.setHeader("X-Trace-Id", traceId)
  F-->>U: X-Trace-Id: abcd-1234

  U->>UI: GET /spider/executions/:no
  UI->>Log: SELECT * WHERE executionNo = no
  Log-->>UI: 全链路 rows
  UI->>UI: 渲染时间线（每节点一行）
```

## 7. 环境变量插值

```
spider_env 表里维护 BASE_URL=https://api.example.com
请求节点 url 配置：{{env.BASE_URL}}/users?page={{ctx.page}}
执行时：
  1. 解析 node props 字符串
  2. 替换 {{env.X}} → SELECT env_value FROM spider_env WHERE env_key = X
  3. 替换 {{ctx.X}} → currentFlowContext.get(X)
  4. 用替换后的字符串发请求
```

## 设计原则

- **复用优先**：不重写 flow 引擎、不重写 cron，组合现有能力
- **缓存写入**：高频读全表缓存，写时整清（allEntries=true）
- **节点注册式**：新节点 = 加一个类 + `@PostConstruct` 注册，不动引擎
- **traceId 贯穿**：从入口 filter 到 logback 到 DB 到前端详情
- **SSE 而非轮询**：浏览器订阅执行链路，状态变化即推送
- **暗色 + 图标化**：开发工具，dark mode first，禁用 emoji，所有图标 SVG
